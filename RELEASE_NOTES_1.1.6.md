# 🎉 1.1.6: The “Clearer Graph Controls” Update

Spatial Task Graph 1.1.6 improves connection actions, settings organization, loading feedback, and compatibility with newer Obsidian desktop versions.

## 🔗 Connection Actions

- Show Search, Cancel, and Create actions while dragging a connection into empty space.
- Keep the action buttons fixed while the connection is being dragged.
- Highlight the action area under the pointer before release.
- Use the upper area to search, the middle button to cancel, and the lower area to create a child task.
- Increase the horizontal distance between the action buttons and the source node.

## ⚙️ Settings and Boards

- Emphasize the TaskNotes integration heading.
- Put archived boards behind a collapsed cabinet section.
- Refresh the graph immediately after archiving a board.
- Add clearer archived-board restore and permanent-delete controls.

## 🖼️ Loading and Task Display

- Blur the canvas while the task index is loading.
- Show a loading indicator instead of presenting an unexplained blank canvas.
- Render task content in bold for easier scanning.
- Align filter checkmarks consistently with the surrounding controls.

## 🧩 Compatibility and Maintenance

- Raise the minimum supported Obsidian version to 1.10.0.
- Use Obsidian element helpers for status menu construction.
- Keep the status menu styling theme-aware.

## 📥 Installation and Updates

1. Open **Settings → Community plugins**.
2. Search for **Spatial Task Graph**.
3. Install or update to version **1.1.6**.
4. Enable or reload the plugin.

Manual installation remains available by downloading `main.js`, `manifest.json`, and `styles.css` from the release assets.
